# FrontierLens 功能演示

## 01 选择研究问题

从一个自然语言研究问题开始，也可以直接选择预置问题。FrontierLens 将问题转化为检索范围，并以 Sciverse Paper Schema 在线语料作为可信数据基础。

## 02 进入研究工作流

系统自动完成问题理解、关键词规划、种子论文检索、结构信息扩展与研究导读生成，将分散论文组织成一条可继续阅读和验证的研究路径。

## 03 论文卡片查看

论文不再只是搜索结果列表。卡片以研究顺序组织标题、贡献与关键摘要，帮助用户快速建立领域脉络，并选择下一篇需要深入阅读的论文。

## 04 图谱网络查看

切换到图谱视图，即可观察论文、实体、论文内关系与已解析引用形成的主题网络。不同语义类别保持独立，支持快速识别核心节点和研究连接。

## 05 论文详情展开

进入单篇论文后，可同时查看结构化概述与 Paper Schema 知识结构。方法组件、实验设置、关键发现和指标均可继续追溯到论文证据与原文位置；除单篇论文导读外，还能沿引用与相关关系连接其他论文拓扑，完成系统性的关联学习。
