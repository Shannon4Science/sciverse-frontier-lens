# FrontierLens Frontend

React, TypeScript, and Cytoscape implementation of the FrontierLens interaction
model:

- full-screen discovery map with research-question sidebar;
- Research Guide with Learning Roadmap and Knowledge Subgraph views;
- Paper Reading Guide with Knowledge Structure and Paper Internal Graph views;
- complete citations, unresolved-reference status, Evidence, and Provenance.

The browser uses only same-origin `/api/*` routes. It has no Sciverse token,
OpenSearch credential, or internal index configuration.
